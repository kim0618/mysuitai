## 필수 질문

1. **생성하기와 편집하기 Sidebar가 픽셀/규격상 동일한가?** 예. `AiBuilderSidebar` 컴포넌트와 `shell.css` 하나를 같이 쓰고, 측정 항목 차이 0개.
2. **중앙은 Existing UView5 iframe 그대로인가?** 예. `#viewer` iframe을 그대로 쓰고, 바깥 Viewer toolbar 복제 0개. 탭 전환으로 `src`가 바뀌지 않는다.
3. **채팅이 제품 UX 형태인가?** 예. 추천 작업, 대화 영역, 말풍선·시간, 입력창과 전송 상태가 있다. provider가 없으면 "AI 연결이 아직 설정되지 않았습니다."만 표시하고 가짜 응답은 없다.
4. **Row move를 사용자가 할 수 있는가?** 예. 셀을 누르면 행 편집이 뜨고, 아래로 이동 → Viewer 반영 → 실행 취소 → 다시 실행 → 저장 → 재로드까지 통과. 병합을 가로지르는 이동은 병합 안내 문구와 함께 거부되고 History에 남지 않는다.
5. **Row delete를 할 수 있는가?** 예. 삭제 → 실행 취소로 복원 → 다시 실행으로 삭제 통과. 데이터가 연결됐거나 직접 수정한 셀이 있는 행은 거부.
6. **Image resize/position을 쓸 수 있는가?** 예. 비율 유지 크기 변경, 가운데 정렬, 표시 끄기/켜기, 맞춤, 이미지 교체까지 통과. 교체는 실행 취소 시 원래 이미지로 돌아온다.
7. **JSON 없이 만든 프로젝트에서 데이터 연결 탭으로 JSON을 새로 추가할 수 있는가?** 예. 파일 선택과 직접 입력 둘 다. 잘못된 JSON은 "JSON 형식이 올바르지 않습니다."만 보이고 Import Context는 바뀌지 않는다.
8. **추가한 JSON으로 단일/반복 연결 검토가 되는가?** 예. HWPX 문서에서 자동 연결 + 수동 수정 후 Viewer에 값 표시, DIM 문서에서 반복 표 `$.items` 자동 연결 후 상품A~C 렌더링. 단, HWPX 표에는 반복 데이터 후보가 나오지 않는다(아래 제한).
9. **Undo/Redo/Save/Reload 후 변경이 유지되는가?** 예. 재로드와 새 브라우저 컨텍스트 모두에서 행·열 순서, 삭제, 이미지 변경, JSON Context, 연결 적용 상태 유지.
10. **기존 회귀가 없는가?** 이번 변경으로 생긴 실패는 없다. 단위 테스트 200/200, 관련 E2E 15종 통과. 실패 4종은 작업 전 코드로도 같은 지점에서 실패하거나 이번 변경과 무관한 조건이다(result JSON `regression` 항목).
